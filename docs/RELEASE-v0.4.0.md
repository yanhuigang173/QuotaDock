# QuotaDock v0.4.0 · Windows 原生版

用于查看本机 Codex 额度和任务状态的 Windows 桌面小组件，以 Rust / Win32 / GDI+ 构建。

## 下载与运行

- **QuotaDock.exe**：单文件程序，直接双击运行。
- **QuotaDock-0.4.0-windows-x64.zip**：含 EXE、快速入门及许可说明的便携包。
- **SHA256SUMS.txt**：以上文件的 SHA-256 校验值。

支持 Windows 10/11 x64。需要本机已安装并登录的 Codex CLI 来读取额度；不需要 WebView2、Electron、Node.js 或 Rust 运行环境。任务通知默认监听本地记录，Hook 为可选功能。

## 本版功能

- 7 天 / 5 小时剩余额度、理想刻度、偏差及重置时间。
- 融合吸附：上下横条、左右竖条，离开边缘恢复紧凑 HUD。
- 平滑悬停展开，双击切换完整窗口并还原位置。
- 本地任务结束通知，显示项目、任务名与摘要，支持字数和行数上限。
- 条形 / 点状状态灯、可同时开启的边缘丝带，四档丝带强度。
- 经典、深海蓝、松林绿、暮光紫、暖砂棕五套主题。
- 重新分组的托盘菜单，保存置顶、底板样式及各项显示偏好。
- 修复置顶、紧凑 HUD 深色底板设置重启丢失。

## 快速操作

拖动移动；融合模式松手后吸附。悬停展开，移开收起。双击切换完整窗口，滚轮缩放，右键打开设置。托盘左键显示 / 隐藏，彻底退出请使用菜单。

状态色：灰色无任务、蓝色进行中、黄绿色本轮完成、橙色已中断。完成提示保留约 3 分钟，中断提示保留约 1 分钟。

## 已知限制

- 本地任务状态依赖 Codex 会话记录格式；云端任务没有本地记录时不支持。
- 本轮结束可能代表等待输入，不保证整个需求已完成。
- 没有明确中止记录的崩溃、断网不能可靠识别为中断。
- CLI 额度协议或会话格式变化后可能需要更新适配。

本版发布准备中完成了 17 项单元测试，以及任务通知、本地记录通知、融合吸附三组集成验证；这些结果不代表所有环境和交互组合均已覆盖。本次补充 README 与打包未另行重跑测试。
